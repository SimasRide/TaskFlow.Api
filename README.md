
# TaskFlow
Aplicação web full-stack para gestão de tarefas. O projeto divide-se numa API desenvolvida em ASP.NET Core e numa interface construída com Angular.

## Tecnologias

**Back-end**
* C# / .NET (ASP.NET Core Web API)
* Entity Framework Core
* SQL Server

**Front-end**
* Angular
* TypeScript
* Tailwind CSS
* HTML5

## Funcionalidades

* Criar novas tarefas
* Listar e pesquisar tarefas existentes
* Atualizar dados ou o estado de uma tarefa
* Remover tarefas
